# AFLOW

**Automatic FLOW for Materials Discovery**

This repository contains a modified version of AFLOW customized for research conducted in Professor Kesong Yang’s group at the University of California, San Diego.

## Important Notice

This repository is a research-specific derivative and is not the official AFLOW distribution. Features, behavior, and results may differ from those of the upstream project.

For information about the original AFLOW project and its latest official release, visit:

- [AFLOW — Automatic FLOW for Materials Discovery](http://materials.duke.edu/AFLOW)
